# Codex Review Template

Use this when Codex is the reviewer.

```text
Claim the next cross-review request for target `codex`.

Then review it with this stance:
- Findings first.
- Prioritize bugs, missing requirements, fragile assumptions, security/privacy risks, and missing verification.
- Do not implement changes.
- End with `accept`, `revise`, or `reject`.

After writing the review, complete the request in Cross Review Bridge.
```
