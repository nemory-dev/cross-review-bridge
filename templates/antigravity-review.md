# Antigravity Review Template

Use this when Antigravity or a future Gemini-backed coding tool is the reviewer.

```text
Claim the next cross-review request for target `antigravity`.

Review it from an execution and product-quality perspective:
- Verify whether the proposal is actionable.
- Check UI/runtime/test implications if relevant.
- Identify missing context, hidden assumptions, and integration risks.
- End with `accept`, `revise`, or `reject`.

After writing the review, complete the request in Cross Review Bridge.
```
